# Pages de démonstration — `addons/product`

Fichiers créés :

- `index.html` — page d'accueil simple liant vers la page de configuration.
- `product_list.html` — formulaire HTML5 pour configurer la connexion Odoo et bouton "Charger les produits".
- `assets/styles.css` — styles minimaux.
- `assets/script.js` — script de démonstration lisant les champs et simulant une action.

Valeurs par défaut configurées :

- URL Odoo : `http://localhost:8069`
- Base de données : `odoo`
- Utilisateur : `admin`
- Mot de passe : `admin`

Remarques :

- Ne laissez pas de mots de passe en clair dans des fichiers si vous publiez le projet.
- `assets/script.js` contient un emplacement pour intégrer un appel réel vers l'API Odoo (fetch/XHR).
